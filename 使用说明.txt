DFL Coach（Deliberate Friction Learning Coach）· 使用说明

一、安装
1. 解压本压缩包。
2. 找到「DFL Coach.app」。
3. 双击打开。

二、如果 macOS 提示“无法验证开发者”
1. 右键点击「DFL Coach.app」。
2. 选择「打开」。
3. 再次点击「打开」即可。

三、首次使用
1. 第一次打开会要求填写 DeepSeek API Key。
2. 把你的 DeepSeek API Key 粘贴进去，点击“保存并开始使用”。
3. API Key 只保存在你自己的电脑上。

四、主要功能
- 电子书模式：导入 .txt / .md / .pdf / .epub 电子书，按章节学习。
- 目录速建模式：没有电子书时，粘贴目录或要点开始学习。
- 管理书架：在 App 内直接导入或移除书籍，也支持从网页链接导入。
- 继续学习：恢复之前保存的学习会话。
- 复习中心：按书籍分类查看所有学习总结。

五、数据保存位置
- macOS：~/Library/Application Support/AiStudyCoach
