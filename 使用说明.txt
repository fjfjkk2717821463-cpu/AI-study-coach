DFL Coach（Deliberate Friction Learning Coach）· 使用说明

一、安装
1. 解压本压缩包。
2. 找到「DFL Coach.app」。
3. 双击打开。

二、如果 macOS 提示“无法验证开发者”
1. 右键点击「DFL Coach.app」。
2. 选择「打开」。
3. 再次点击「打开」即可。

三、首次使用
1. 第一次打开会要求填写 DeepSeek API Key。
2. 把你的 DeepSeek API Key 粘贴进去，点击“保存并开始使用”。
3. API Key 只保存在你自己的电脑上。

四、主要功能
- 电子书模式：导入 .txt / .md / .pdf / .epub 电子书，按章节学习。
- 目录速建模式：没有电子书时，粘贴目录或要点开始学习。
- 管理书架：在 App 内直接导入或移除书籍，也支持从网页链接导入。
- 继续学习：搜索、重命名、删除历史会话，并一键继续。
- 重新生成：对教练的回答不满意时，点击「↻ 重新生成」。
- 多模型设置：点「⚙️ 模型设置」可选择 DeepSeek、OpenAI、智谱、通义千问、Kimi、硅基流动或任意 OpenAI 兼容接口。
- 章节搜索：选择章节时可直接输入关键词过滤下拉列表。
- 复习中心：按书籍分类查看所有学习总结。

五、数据保存位置
- macOS：~/Library/Application Support/AiStudyCoach

六、远程访问说明
- 本机桌面使用无需密码。
- 局域网手机访问：启动「手机访问.command」后会显示访问密码，在手机浏览器输入即可。
- 云端部署：需要在服务端设置 APP_PASSWORD 环境变量作为访问密码。
- 网页导入功能会拒绝访问本地、内网和保留地址，请填写公开网页地址。
