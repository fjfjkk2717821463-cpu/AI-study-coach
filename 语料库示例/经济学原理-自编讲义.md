# 第一章 需求与供给

## 1.1 需求

需求描述的是在其他条件不变时，某种商品的价格与消费者愿意并且能够购买的数量之间的关系。
把每一价格水平上对应的购买量连起来，就得到需求曲线。需求曲线通常向右下方倾斜，
因为价格下降时，替代效应让这种商品相对便宜，收入效应让消费者的实际购买力上升。

要区分两个容易混淆的说法：需求量的变动，是指价格变化引起的沿着同一条曲线的移动；
需求的变动，是指收入、偏好、相关商品价格等价格以外的因素变化引起的整条曲线的平移。

影响需求的主要因素包括：

- 消费者收入水平
- 相关商品的价格，包括替代品与互补品
- 消费者偏好与预期
- 消费者人数与结构

一个常见的错误是把需求曲线向下倾斜当成一条自然规律。在某些特殊情形下，
价格上升反而带来需求量上升，这类商品被称为吉芬商品，它的存在需要同时满足收入效应极强、
且该商品在消费结构中占比很高等条件。

## 1.2 供给

供给描述的是在其他条件不变时，价格与生产者愿意并且能够出售的数量之间的关系。
供给曲线通常向右上方倾斜：价格上升时，原有生产者扩大产量，新的生产者也可能进入市场。

影响供给的因素包括生产成本、技术水平、相关商品价格、生产者预期以及生产者数量。
其中生产成本的变化会直接推动整条供给曲线平移，这一点在生产与成本一章会进一步展开。

## 1.3 均衡

当需求量等于供给量时，市场处于均衡状态，对应的价格称为均衡价格，对应的数量称为均衡数量。
如果现行价格高于均衡价格，出现超额供给，卖方之间的竞争会把价格压低；
如果现行价格低于均衡价格，出现超额需求，买方之间的竞争会把价格抬高。

需要提醒的是，均衡是一种分析结论，而不是对现实市场每时每刻状态的描述。
现实中的价格调整需要时间，也会受到制度与信息的限制。

| 情形 | 市场状态 | 价格变化方向 |
| --- | --- | --- |
| 现行价格高于均衡价格 | 超额供给 | 下降 |
| 现行价格低于均衡价格 | 超额需求 | 上升 |
| 现行价格等于均衡价格 | 均衡 | 不变 |

# 第二章 弹性

## 2.1 需求价格弹性

需求价格弹性衡量的是需求量对价格变化的敏感程度，等于需求量变化的百分比除以价格变化的百分比。

用公式表示：需求价格弹性等于需求量变动百分比除以价格变动百分比。

这里的分子和分母都是百分比变化，而不是绝对量的变化。这一点决定了同一条需求曲线上
不同位置的弹性并不相同：在价格较高的位置，同样的价格变动对应的百分比更小，弹性通常更大。

## 2.2 弹性的分类

按照弹性绝对值的大小，可以把需求分为三类：

- 富有弹性：弹性绝对值大于 1，需求量变化幅度大于价格变化幅度
- 缺乏弹性：弹性绝对值小于 1，需求量变化幅度小于价格变化幅度
- 单位弹性：弹性绝对值等于 1，两者变化幅度相同

两个边界情形值得单独记住：需求完全无弹性时弹性为零，需求曲线是一条垂直线；
需求完全有弹性时弹性趋于无穷大，需求曲线是一条水平线。

## 2.3 弹性与斜率不是一回事

斜率衡量的是两条轴上绝对量的变化之比，弹性衡量的是百分比变化之比。
同一条直线形式的需求曲线上，各点斜率相同，但弹性会随着位置变化而变化。
把弹性当作斜率是本课程中最常见的理解错误。

## 2.4 弹性与税负分担

税收在买卖双方之间的分担比例取决于供求双方的相对弹性。
弹性较小的一方对价格变化的反应更弱，承担更多税负；弹性较大的一方更容易退出交易，承担较少税负。
当需求几乎无弹性时，例如食盐这类必需品，税负主要由消费者承担。

# 第三章 消费者行为

## 3.1 效用与边际效用

效用是消费者从消费商品中获得的满足程度。基数效用论假设效用可以用数值表示，
序数效用论则只要求消费者能够对不同的消费组合排序。

边际效用是指每增加一单位消费所带来的总效用的增量。边际效用递减规律指出，
在其他条件不变时，随着消费量增加，每新增一单位带来的效用增量趋于下降。

这里有一个容易被忽略的区分：边际效用递减说的是增量在下降，并不等于总效用也在下降。
只要边际效用仍然为正，总效用就仍在上升；只有当边际效用变为负值，总效用才开始下降。

## 3.2 消费者均衡

在收入有限的条件下，消费者通过把最后一元钱花在每种商品上所带来的边际效用调整到相等，
来实现效用最大化。这一条件可以写成：两种商品的边际效用与价格之比相等。

如果某一种商品的边际效用与价格之比更高，消费者就会把支出从另一种商品转移过来，
直到两者相等为止。

## 3.3 需求曲线的再解释

用边际效用递减可以重新解释需求曲线向下倾斜：价格下降时，每一元钱能够买到的边际效用上升，
消费者愿意并且能够购买的数量随之增加。这条解释路径与前面的替代效应、收入效应并不矛盾，
它们是从不同角度描述同一现象。

# 第四章 生产与成本

## 4.1 短期生产函数

生产函数描述投入与产出之间的技术关系。短期内，至少有一种要素无法调整，
通常把资本视为固定要素，把劳动视为可变要素。

总产量、平均产量与边际产量之间满足一个重要关系：边际产量曲线穿过平均产量曲线的最高点。
当边际产量高于平均产量时，平均产量上升；当边际产量低于平均产量时，平均产量下降。

## 4.2 边际报酬递减

边际报酬递减规律指出，在技术水平不变、其他要素投入量固定的条件下，
连续增加某一种可变要素，边际产量最终会下降。

这条规律说的是最终会下降，而不是一开始就下降。生产初期往往存在专业化分工带来的效率提升，
边际产量可能先上升，越过某一点之后才开始下降。

## 4.3 短期成本

与产量概念对应，短期成本可以分为总固定成本、总可变成本与总成本。

- 固定成本不随产量变化，例如厂房租金
- 可变成本随产量变化，例如原材料与计件工资
- 边际成本是每增加一单位产量所增加的总成本

由于边际报酬递减的存在，边际成本曲线通常先下降后上升，并穿过平均可变成本与平均总成本的最低点。
理解这一点，是后面分析完全竞争市场厂商供给曲线的基础。
