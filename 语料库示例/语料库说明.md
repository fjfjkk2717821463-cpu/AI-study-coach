# 语料库说明

这个目录放的是随作品一起开源的教学语料库示例，用于两件事：一是复现作品的学习流程，
二是给要换用自己教材的学校一个可参照的加工样例。

## 一、语料从哪里来

目录里的两份讲义由本项目自行编写，内容是学科通用知识的重新组织与表述，
不是从任何教材复制粘贴而来。这样处理有两个原因：

1. 参赛作品的知识产权条款要求参赛者对使用的第三方内容自行负责，开源仓库里放受版权保护的教材原文并不合适；
2. 自编内容可以随作品一起分发，评审和其他学校拿到仓库就能直接复现，不依赖任何外部文件。

学校试用时把这里替换成自己的材料即可：教师自编讲义、学校已购买的教材电子版、
或者国家智慧教育平台等公开授权资源。作品本身不内置、也不分发任何受版权保护的教材内容。

## 二、加工流程

语料进入学习流程之前会经过四步加工，每一步都在程序里完成，可以重复执行：

1. **格式解析**：读取 `.md` / `.txt` / `.pdf` / `.epub`，PDF 优先用版式解析工具，失败时逐级降级；
2. **结构化**：统一转成 Markdown，保留标题层级、列表、表格，让结构信息一路保留到提示词里；
3. **章节切分**：按 Markdown 标题与常见章节标题切分，支持"自动 / 大章节 / 小章节"三种粒度；
4. **按需注入**：学习某一章时只把这一章的原文放进模型上下文，既降低幻觉也压低开销。

## 四、换用学校自己的材料

1. 把教材或讲义放进任意目录；
2. 在作品里用「管理书架」导入，或直接调用 `book_utils`；
3. 先跑一遍统计脚本，检查章节切分是否符合预期：

```bash
python tools/corpus_report.py 你的目录
```

4. 如果某份材料切分不理想（例如扫描版 PDF 没有文本层、或者章节标题不规范），
   报告里会直接显示章节数和平均长度异常，可以据此决定是否先做 OCR 或人工整理目录。

## 五、使用范围提醒

学校在使用自己的教材时，建议把语料范围限定在校内教学使用，并在试用前确认三件事：
教材电子版的来源是否合法、是否允许转成结构化文本、以及试用结束后是否需要删除副本。
这三点与作品本身无关，但属于学校需要走的合规流程。
