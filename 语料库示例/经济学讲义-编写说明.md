# 经济学自编讲义·编写说明

这份说明回答两个问题：**讲义的内容可靠吗？版权干净吗？**
它也交代了审定流程，方便指导教师、评审和试用学校核对。

## 一、为什么自己写讲义

大赛要求参赛作品"自选自建数据语料库"。用现成教材有两个问题：
一是教材原文受版权保护，放进开源仓库和演示材料都不合适；
二是教材往往没有按"先讲清楚、再检测理解"的方式组织，不适合直接作为学习语料的骨架。

因此团队选择自己编写：**知识点来自学科共识，表述、例子、表格与误区归纳全部自己写。**

## 二、内容覆盖

讲义按经济学原理课程的标准体系组织，共 8 讲，覆盖微观与宏观两部分：

| 讲次 | 主题 | 主要知识点 |
| --- | --- | --- |
| 第一讲 | 需求与供给 | 需求法则、需求量变动与需求变动、供给、市场均衡与比较静态分析 |
| 第二讲 | 弹性及其应用 | 需求价格弹性与中点法、弹性分类、弹性与斜率的区别、收入弹性与交叉弹性、税负分担 |
| 第三讲 | 消费者行为 | 效用与边际效用递减、等边际原则、替代效应与收入效应 |
| 第四讲 | 生产与成本 | 短期生产函数、边际报酬递减、成本分类、边际成本与平均成本的关系、规模经济 |
| 第五讲 | 市场结构 | 完全竞争、垄断、垄断竞争、寡头与博弈、四种结构的对比 |
| 第六讲 | 市场失灵与政府干预 | 外部性与科斯定理、公共品与公共资源、信息不对称、干预的成本 |
| 第七讲 | 宏观经济的衡量 | GDP 的定义与三种核算方法、名义与实际、价格指数、失业的类型 |
| 第八讲 | 总需求、总供给与政策 | AD-AS 模型、财政政策与乘数、货币政策与传导链条、两种政策的取舍 |

规模：**5780 字，切分为 8 讲、33 个小节**（统计口径见 `语料库统计报告.md`，由作品自身的文档处理模块生成）。

## 三、可靠性怎么保证

**第一，知识点本身是学科共识。** 上面列出的每一条都是国内外《经济学原理》课程的标准内容，
教师可以拿任何一本主流教材逐条对照，结论一致。

**第二，表述与例子是自己写的。** 讲义不使用教材原文、图表、案例与习题，
例子（食盐与奶茶的弹性、一杯水的边际效用、公共渔场的过度使用等）都是团队自行设计的通俗场景。

**第三，每讲固定结构，便于核对。** 每一讲都按「定义 → 直觉解释 → 例子 → 边界与反例 → 常见误区」组织，
最后单列常见误区。教师只看误区一节，就能判断这一讲是否讲得准确、是否抓住了学生容易错的地方。

**第四，有审定环节。** 讲义由团队编写，提交指导教师逐讲审定；项目试点阶段可由任课教师复核并签署意见，
审定记录随申报材料一并保存。答辩现场如果被问到"AI 讲错了怎么办"，
标准答案是：教学内容由任课教师审定，系统只负责按讲义原文组织讲解与检测，不自行发明知识。

## 四、版权怎么处理

- 讲义不复制、不改编任何受版权保护的教材内容，也不包含教材的图表、习题与案例；
- 讲义以 **CC BY-NC-SA 4.0**（署名—非商业性使用—相同方式共享）授权，
  任何学校都可以在校内教学中免费使用与改编，只需保留署名并以相同方式共享；
- 项目代码以 MIT 授权，讲义与代码的授权范围分开说明，避免混淆；
- 学校试用时若导入自有教材，教材的版权与使用范围由学校自行确认，
  作品本身不内置、不分发这些内容；试用结束后副本如何处理，按学校规定执行。

## 五、学校要换成自己的教材时

1. 把教材或自编讲义放进任意目录；
2. 先跑一遍统计脚本，检查章节切分是否符合预期：

```bash
python tools/corpus_report.py 你的目录
```

3. 在作品里用「管理书架」导入即可。若切分不理想（扫描版 PDF 没有文字层、标题层级混乱等），
   报告里的"章节数"和"平均章节长度"会明显异常，据此决定是否先做 OCR 或人工整理目录。
