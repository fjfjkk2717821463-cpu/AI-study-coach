# 第一章 线性表

## 1.1 顺序存储与链式存储

线性表是最基本的线性结构，元素之间存在一对一的相邻关系。实现方式主要两种：
顺序存储用一段连续空间保存元素，链式存储用指针把分散的结点串起来。

两种实现的核心差别在于随机访问与插入删除的代价：

- 顺序存储支持按下标直接访问，时间复杂度为常数级；但中间插入或删除需要搬移元素
- 链式存储插入删除只需改动指针；但按下标访问必须从头逐个走

选择哪一种，取决于程序里"读"和"改"的比例。读多改少时顺序存储通常更合适。

## 1.2 单链表的基本操作

单链表的插入需要先找到前驱结点，再把新结点的指针指向后继结点，最后让前驱指向新结点。
顺序不能颠倒，否则会丢失后继结点的地址。

删除操作同样需要前驱结点：让前驱直接指向被删结点的后继，再释放被删结点。
这里有一个常见错误是用被删结点自己的指针去改，结果只能改到自己，链表结构没有变化。

# 第二章 栈与队列

## 2.1 栈

栈是只允许在一端插入和删除的线性表，遵循后进先出。典型应用包括括号匹配、
表达式求值、函数调用栈与深度优先搜索。

括号匹配的判定逻辑是：遇到左括号入栈，遇到右括号时检查栈顶是否为对应的左括号；
扫描结束时栈必须为空。任何一步不满足，匹配就失败。

## 2.2 队列

队列只允许在一端插入、在另一端删除，遵循先进先出。典型应用包括任务调度、
广度优先搜索与缓冲区管理。

用顺序存储实现队列时会出现假溢出：数组尾部已满但头部还有空位。
解决办法是把它做成循环队列，用取模运算把下标绕回数组开头。
循环队列需要额外区分空与满，常见做法是牺牲一个存储单元，或者额外记录元素个数。

# 第三章 排序

## 3.1 比较类排序的下界

冒泡、插入、归并、快速排序都属于比较类排序。这类算法通过两两比较决定元素次序，
其时间复杂度下界是 n log n：n 个元素共有 n 的阶乘种排列，
每次比较最多把可能性分成两半，因此至少需要 log(n!) 次比较。

理解这条下界有助于判断算法的改进空间：如果某个比较类排序声称平均复杂度低于 n log n，
那一定在某个环节偷换了假设。

## 3.2 快速排序

快速排序选择一个基准元素，把序列划分成小于基准与大于基准两部分，再分别递归处理。
平均时间复杂度为 n log n，最坏情况退化为 n 的平方。

退化的原因是划分极度不平衡，例如每次选的基准都是当前区间的最大值或最小值。
常见的改进是随机选择基准或采用三数取中，把出现极端划分的概率降到很低。

## 3.3 稳定性

排序的稳定性指相等元素在排序前后的相对次序是否保持不变。多关键字排序时它很重要：
先按次要关键字排一次，再按主要关键字排一次，只要第二次使用的算法稳定，最终结果就是正确的。

归并排序与插入排序是稳定的，快速排序与选择排序是不稳定的。
