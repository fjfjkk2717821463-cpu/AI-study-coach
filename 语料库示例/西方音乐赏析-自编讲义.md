# 第一讲 听音乐的三把钥匙

## 1.1 从"听到什么"开始

初听一段音乐，最容易被抓住的是旋律，最容易忽略的是它底下发生的事。
一段音乐真正在做什么，通常由三件事共同决定：旋律怎么走、节奏怎么安排、各声部怎么叠在一起。

**旋律**是一条能被记住的线。它由音高走向和音程关系构成：

- 级进：相邻音之间小步移动，听感通常是平稳、叙述性的
- 跳进：跨越较远的音，听感更跳跃，常用来制造情绪起伏
- 模进：把同一个旋律型在不同高度重复，用来积累推动力

**节奏**处理的是时间关系，不只是快慢。同样一段旋律，把重音位置移动一个单位，
听感会完全不同。节拍的强弱规律决定了音乐的"重心"在哪。

## 1.2 和声与织体：音乐为什么"有厚度"

**和声**是同时发声的音之间的关系。它决定了音乐的紧张与松弛：
协和音程听起来稳定，不协和音程需要被解决，而"需要被解决"正是音乐向前走的动力来源。

**织体**是各声部的组织方式，常见三类：

- 主调织体：一条主旋律加伴奏，听众注意力集中在最上方
- 复调织体：多条独立旋律同时进行，每条都值得单独听
- 全奏式：所有声部同起同落，用于营造气势或段落收束

巴洛克时期的赋格是复调的代表，古典时期的主调织体更常见，
到了浪漫时期两者常常混用。

| 要素 | 在问什么 | 听觉线索 |
| --- | --- | --- |
| 旋律 | 这条线怎么走 | 级进还是跳进，是否模进 |
| 节奏 | 时间怎么组织 | 重音落在哪，是否切分 |
| 和声 | 紧张还是松弛 | 是否不协和，是否解决 |
| 织体 | 声部怎么叠 | 一条主线还是多条并行 |

## 1.3 音色与配器

音色是乐器的"嗓音"。同一段旋律交给弦乐、木管或铜管，听感差别远超大多数人的预期。
描述音色时尽量具体：不是"很好听"，而是"长笛在这句里声音偏冷、颗粒清楚"。

听到配器时值得追问一句：作曲家为什么把这一段交给这件乐器，而不是另一件。

# 第二讲 曲式：音乐的建筑

## 2.1 为什么需要曲式

音乐是时间的艺术，听众需要一个可以抓住的结构。曲式就是作曲家在时间里搭起来的建筑，
它回答的是"接下来会听到什么、什么时候回来"这两个问题。

## 2.2 常见曲式

- **二部曲式**：两个对比段落，通常形成陈述与回应
- **三部曲式**：陈述、对比、再现，是最容易被感知的结构
- **回旋曲式**：主部多次回归，中间插入不同的插部
- **变奏曲式**：主题保持不变，每次出现改变织体、节奏或音色
- **奏鸣曲式**：呈示部、展开部、再现部三段结构，器乐作品中最具戏剧性的一种

奏鸣曲式的关键在于两个主题的性格对比：第一主题通常更有力，第二主题通常更抒情，
展开部把这些材料拆开重组，再现部把它们带回同一条轨道上。

| 曲式 | 结构 | 听觉标志 |
| --- | --- | --- |
| 三部曲式 | A-B-A | 开头段落完整回来 |
| 回旋曲式 | A-B-A-C-A | 主部反复出现且容易被记住 |
| 变奏曲式 | A-A1-A2-A3 | 主题不变，外壳不断变化 |
| 奏鸣曲式 | 呈示-展开-再现 | 两个对比主题，中段最动荡 |

## 2.3 用曲式听结构的练习

听一部交响曲的某个乐章时，先不要看讲解，试着回答三个问题：
有没有一个让人记住的主题，它在多长时间后再次出现，再次出现时有没有变化。
能把这三个问题答出来，就已经抓住了这个乐章的大结构。

# 第三讲 风格分期与听赏要点

## 3.1 四个时期的基本印象

**巴洛克（约 1600-1750）**：织体密集、节奏持续推动、装饰音多。
巴赫的赋格是这一时期的顶点，适合用来练习"同时听多条线"。

**古典（约 1750-1820）**：结构清晰、比例均衡、旋律优先。
莫扎特的交响曲与协奏曲是理解这一时期的起点，贝多芬把它的结构张力推到了边界。

**浪漫（约 1820-1900）**：情感表达优先，和声更复杂，乐队规模扩大，
出现了标题音乐与艺术歌曲。舒伯特的《魔王》用一架钢琴和一位歌者讲完一个故事。

**二十世纪及之后**：调性体系被扩展甚至放弃，节奏与音色成为新的组织手段。
需要注意，二十世纪作曲家的作品多数仍在版权保护期内，教学选用时要单独确认授权。

## 3.2 风格判断的线索

判断一段音乐大致属于哪个时期，可以先问四个问题：旋律是否规整、和声是否紧张、
乐队规模多大、节奏是否稳定。这四条线索比背年代更实用。

# 第四讲 如何写一段音乐赏析

## 4.1 赏析不是术语的堆砌

课堂上最常见的问题，是把赏析写成了术语清单：
"本曲为奏鸣曲式，第一主题在c小调，副部主题转入降E大调，展开部运用了动机分裂与模进。"
这段话没错，但它没有说明音乐在做什么，也没有说明听者感受到了什么。

好的赏析要回答三个层次的问题：

1. **听到了什么**：描述具体的听觉事实，例如"低音持续敲击同一个音，其他声部在它上面盘旋"
2. **音乐做了什么**：说明它用了什么手法，例如"低音像心跳一样固定，上方声部的不协和音不断累积"
3. **为什么这样**：把手法与效果联系起来，例如"这种固定与不安的对比，也是这个乐章紧张感的来源"

## 4.2 术语的正确位置

术语是用来指路的，不是用来代替观察的。一个可执行的检验方法是：
把自己写的一段赏析读给没学过音乐的人听，如果他只能听懂一半，
说明还有一半藏在术语后面，需要重新讲一遍。

## 4.3 一段合格的赏析示例

以贝多芬第五交响曲第一乐章的开头为例，可以这样写：
"开头四个音很短，力量很集中，它在整首曲子里反复出现，只是不断换到不同的乐器和高度上。
听的时候会感觉这个短句像一块被反复投掷的石头，后面的音乐都在回应它。
这就是动机式的写法：用最小的材料组织起整个乐章。"

这段话没有出现"奏鸣曲式"或"动机分裂"这类术语，但它讲清了材料的角色与效果，
术语可以在后面作为补充，而不是开头的门面。

## 4.4 常见误区

- 只写背景故事，不谈音乐本身
- 只写情绪形容词，缺少听觉事实
- 术语密度很高，但听感描述为零
- 把作曲家生平当作赏析主体
