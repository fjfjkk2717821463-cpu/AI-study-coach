# 第一章 变量与数据类型

## 1.1 变量是名字，不是盒子

变量是给值起的名字。`x = 3` 的含义是让名字 `x` 指向整数对象 3，
而不是把 3 装进一个叫 x 的盒子里。这一点解释了后面很多看起来奇怪的现象。

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)   # [1, 2, 3, 4]
```

`a` 和 `b` 指向同一个列表对象，通过任一名字修改它，另一个名字看到的结果也会变化。
如果需要一份独立副本，必须显式复制：`b = list(a)` 或 `b = a[:]`。

## 1.2 可变与不可变

Python 的数据类型可以分成两类：

- 不可变类型：整数、浮点数、字符串、元组。修改它们实际上是创建新对象
- 可变类型：列表、字典、集合。可以在原对象上修改

这个区分决定了函数参数传递时的行为，也决定了字典的键为什么不能是列表。

| 类型 | 可变性 | 能否作为字典键 |
| --- | --- | --- |
| 整数、字符串 | 不可变 | 可以 |
| 元组（元素不可变） | 不可变 | 可以 |
| 列表 | 可变 | 不可以 |
| 字典 | 可变 | 不可以 |

# 第二章 控制流与循环

## 2.1 条件判断

`if` 语句按顺序检查条件，第一个成立的分支被执行，其余分支不再判断。
条件的真假判断遵循"真值测试"规则：空列表、空字符串、0 与 None 都被视为假。

写条件时最常见的错误是把赋值写成比较：`if x = 1` 是语法错误，
而 `if x == 1` 才是比较。另一种隐蔽的错误是把 `is` 当作 `==` 使用：
`is` 比较的是两个名字是否指向同一个对象，而不是值是否相等。

## 2.2 循环

`for` 用于遍历可迭代对象，`while` 用于在条件成立时重复执行。
循环体里通常需要配合 `break`、`continue` 与 `else` 使用。

需要特别说明的是 `for ... else` 结构：`else` 分支在循环正常结束（没有被 break 中断）时执行，
常用来处理"查找失败"的情况。

```python
for item in data:
    if item == target:
        print("找到了")
        break
else:
    print("没有找到")
```

## 2.3 遍历时的修改问题

遍历列表的同时删除元素，会导致元素被跳过。安全做法是遍历副本，或构造新列表：

```python
result = [x for x in data if x >= 0]
```

# 第三章 函数与作用域

## 3.1 函数是封装，不是跳转

函数的价值在于把一段逻辑命名，并限定它能看到哪些数据。
调用函数时，实参对象被绑定到形参名上；函数内部对不可变对象的修改不会影响外部，
对可变对象的原地修改会影响外部。这正好回到第一章的可变性问题。

## 3.2 作用域规则

Python 查找名字的顺序是局部、闭包、全局、内置，通常称为 LEGB 规则。
在函数内部给一个名字赋值，会让它成为局部变量，即使外部存在同名变量。
如果确实需要修改全局变量，必须显式声明 `global`，但更好的做法是把状态作为参数传入、
把结果作为返回值传出。

## 3.3 默认参数的陷阱

默认参数只在函数定义时求值一次。用可变对象作为默认值，会在多次调用之间共享同一个对象：

```python
def add_item(item, box=[]):
    box.append(item)
    return box
```

连续调用 `add_item(1)` 与 `add_item(2)`，第二次会看到累积结果。
正确写法是把默认值设为 `None`，在函数体内按需创建新列表。
